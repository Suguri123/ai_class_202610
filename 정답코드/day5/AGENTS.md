# AI 비서 작업 규칙

## 기본 규칙
- 항상 한국어 존댓말(~습니다 체)로, 초보자도 이해할 수 있게 짧고 쉽게 설명하기
- 웹페이지는 HTML 파일 하나에 CSS와 JavaScript를 모두 넣기
- 외부 라이브러리는 CDN 주소로만 불러오고, 프로그램 설치나 서버 실행은 하지 않기
- 파일을 만들거나 고친 뒤에는 파일 이름과 여는 방법 알려 주기 (웹페이지는 서버 없이 크롬 주소창에 파일 경로를 넣어 바로 여는 방법으로)
- 지시하지 않은 파일은 지우거나 고치지 않기
- 나에게 무엇을 묻거나 허락을 구할 때는 항상 한국어 번역을 함께 달기 (영어로 된 질문이나 선택지에는 괄호로 한국어 뜻을 붙이고, 명령을 실행하기 전에는 무엇을 하려는지 한국어로 먼저 설명하기)

## 아두이노 규칙 (3차시에 추가)
- 보드: Arduino Uno
- 코드는 '스케치이름/스케치이름.ino' 형태로 저장
- 코드 한 줄마다 쉬운 한국어 주석
- 시리얼 통신 속도는 항상 9600
- 핀 번호: 빨강 LED 9번, 노랑 LED 10번, 초록 LED 11번, 부저 8번, 서보모터 7번
- RGB LED: 빨강 3번, 초록 5번, 파랑 6번
