바이브 코딩

코드를 외우지 않고 "이런 걸 만들어 줘"라고 말로 설명해 프로그램을 만드는 방법.

오늘 쓰는 AI 비서는 구글의 무료 도구 Antigravity CLI입니다. 명령어 이름은 agy이며, 까만 창(터미널)에서 대화하듯 일을 시킵니다.

  1. 1

    파워셸(PowerShell) 열기

    파워셸 = 컴퓨터에 글자로 명령하는 까만(또는 파란) 창.

    1. 키보드의 ⊞ Windows 키 누르기
    2. powershell 입력
    3. Windows PowerShell 클릭 (Windows 11은 시작 버튼 오른쪽 클릭 → 터미널도 가능)
    관리자 창은 쓰지 않기 시작 버튼 오른쪽 클릭 메뉴에서는 터미널(관리자)가 아닌 터미널 선택. 줄 앞이 PS C:\WINDOWS\system32>로 보이면 관리자 창이므로 닫고 다시 열기 (AI 비서가 명령을 실행하므로 일반 창이 안전).
    붙여넣기: Ctrl+V 또는 마우스 오른쪽 클릭. 화면 정리: ⊞+← / ⊞+→로 이 사이트와 파워셸을 반반 배치.

    이렇게 되면 성공! PS C:\Users\이름> 같은 글자 뒤에서 커서가 깜빡임.

  2. 2

    AI 비서 설치하기

    출처: 구글 공식 안내 Antigravity CLI 설치와 로그인 (antigravity.google) · 공식 GitHub 저장소. 아래 설치 명령어는 이 안내와 같음.

    아래 명령어를 파워셸에 붙여넣고 Enter. 설치 글자가 모두 지나갈 때까지 대기.

    Windows PowerShell파워셸 창에 붙여넣고 Enter
    irm https://antigravity.google/cli/install.ps1 | iex
    설치 화면 읽는 법 ERROR: logging before google.Init로 시작하는 줄이 여러 개 나와도 오류가 아닌 설치 기록. ✅ Antigravity CLI binary placed successfully 줄이 보이면 설치 성공. 그 근처의 Warning · Note 문장은 '창을 새로 열라'는 안내.
    중요! 설치가 끝나면 파워셸 창을 완전히 닫고 새로 열기 (탭이 여러 개면 모두 닫기). 설치한 창에서 바로 agy --version을 입력하면 '인식되지 않습니다' 오류가 남.

    새 창에서 설치 확인.

    Windows PowerShell파워셸 창에 붙여넣고 Enter
    agy --version

    이렇게 되면 성공! 1.3.3처럼 숫자(버전)가 나옴. 업데이트에 따라 숫자가 달라도 무관.

    안 되면?
    'agy' 용어가 cmdlet, 함수… 이름으로 인식되지 않습니다설치한 창을 그대로 쓴 경우. 파워셸(터미널) 창을 모두 닫고 새로 열기. 그래도 안 되면 아래 명령어를 붙여넣고 Enter 후 다시 agy --version (지금 창에만 적용). 계속 안 되면 노트북 재시작.
    Windows PowerShell파워셸 창에 붙여넣고 Enter
    $env:Path += ";$env:LOCALAPPDATA\agy\bin"
    이 시스템에서 스크립트를 실행할 수 없으므로…아래 명령어를 붙여넣고 Enter → Y 입력 후 다시 설치.
    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
    설치 명령어에서 빨간 오류 발생명령 프롬프트(⊞ 키 → cmd)를 열고 아래 명령어로 설치.
    curl -fsSL https://antigravity.google/cli/install.cmd -o install.cmd && install.cmd && del install.cmd
    회사·기관 노트북인 경우보안 설정으로 설치가 막혀 있을 수 있음. 강사에게 알리기.
  3. 3

    수업 폴더 만들고 AI 비서 시작하기

    실습 파일은 C:\ai-class 안에 차시마다 폴더를 하나씩(day1~day6) 만들어 저장. 오늘은 day1 폴더. 아래 명령어 한 줄로 폴더 만들기 → 폴더로 이동 → AI 비서 켜기까지 한 번에 진행.

    Windows PowerShell파워셸 창에 붙여넣고 Enter
    mkdir C:\ai-class\day1 -Force; cd C:\ai-class\day1; agy

    처음 한 번만 로그인.

    1. 로그인 방법에서 Google OAuth 선택 후 Enter
    2. 브라우저가 열리면 내 구글 계정 선택 → 허용
    3. 화면에 인증 코드가 보이면 복사해 까만 창에 붙여넣고 Enter (코드 없이 '완료'만 보이면 까만 창으로 복귀)
    4. 색 테마·모델 선택 같은 질문은 Enter(기본값), 약관은 동의(Accept) 선택
    AI 비서는 켠 폴더 안에서만 일함 VS Code에서 폴더를 여는 것과 같음. 오늘 다시 켤 때는 cd C:\ai-class\day1; agy. 다음 차시부터는 그날 폴더(day2, day3 …)를 준비하고 그 폴더에서 켬. agy만 입력하면 파일이 엉뚱한 폴더에 생기고 규칙표(AGENTS.md)도 적용되지 않음.

    이렇게 되면 성공! 창 아래쪽에 글을 쓰는 입력칸(>)이 보임.

    안 되면?
    브라우저가 열리지 않음까만 창에 나온 https://… 주소를 마우스로 드래그해 복사 → 크롬 주소창에 붙여넣기.
    회사·기관 구글 계정으로 로그인 불가회사·기관 계정은 관리자 설정으로 막혀 있을 수 있음. 개인 Gmail 계정으로 로그인.
    영어 질문이 나옴대부분 Enter(기본값)로 통과. 모르겠으면 강사에게 도움 요청.
  4. 4

    AI 비서와 첫 대화

    첫 질문 보내기. 아래 상자를 복사해 입력칸에 붙여넣고 Enter.

    AI 비서에게검은 창 아래 입력칸(>)에 붙여넣고 Enter
    안녕! 너는 무엇을 할 수 있는지 컴퓨터를 처음 배우는 사람도 알기 쉽게 3줄로 소개해 줘.
    상황방법
    질문 보내기Enter
    AI가 일하는 중 멈추기Esc
    AI가 Do you want to proceed?(진행 여부 확인)라고 물을 때내용을 읽고 1. Yes에서 Enter (모르겠으면 No 선택 후 강사에게 문의)
    남은 무료 사용량 보기/usage 입력 후 Enter
    AI 비서 끝내기/exit 입력 후 Enter
    한글을 직접 입력해도 되지만, 글자가 이상하게 보이면 이 사이트에서 복사해 붙여넣는 방법이 가장 확실합니다.

    이렇게 되면 성공! AI가 한국어로 자기소개를 함.

  5. 5

    AI 비서에게 작업 규칙 알려 주기

    AGENTS.md = AI 비서가 일을 시작할 때마다 먼저 읽는 규칙표. 한 번 만들어 두면 매번 길게 설명할 필요 없음. 규칙표는 폴더마다 하나이며, 다음 차시에는 그날 폴더로 복사해서 씀. 1번 규칙 덕분에 이후 AI 답변은 존댓말(~습니다 체)로 나오고, 6번 규칙 덕분에 AI가 무언가를 물을 때 영어 문장 옆에 한국어 번역이 함께 붙음.

    AI 비서에게검은 창 아래 입력칸(>)에 붙여넣고 Enter

## 기본 규칙
- 항상 한국어 존댓말(~습니다 체)로, 초보자도 이해할 수 있게 짧고 쉽게 설명하기

  1. 1

    Antigravity IDE 설치하고 오늘 폴더 열기

    오늘부터 AI 비서는 까만 창 대신 Antigravity IDE에서 씁니다. 1차시의 AI 비서와 같은 구글의 AI이고, 같은 구글 계정으로 로그인합니다. 왼쪽에 폴더의 파일 목록, 오른쪽에 AI 대화창(AI 패널)이 함께 보여서 어떤 파일이 생기고 바뀌는지 바로 확인할 수 있습니다.

    ① 설치 (처음 한 번)

    크롬 주소창주소창에 붙여넣고 Enter
    antigravity.google/download
    1. 다운로드 화면에서 Antigravity IDE (Standalone) 항목의 Download for x64 클릭 (맨 위의 Antigravity 2.0이 아님)
    2. 내려받은 Antigravity IDE.exe 실행 → 설치 창은 기본값 그대로 Next(다음) → Install(설치) → Finish(마침)

    ② 처음 설정 · 로그인 (처음 한 번)

    1. 처음 화면에서 Start fresh(새로 시작) → Next
    2. 화면 색(테마)과 AI 사용 방식은 Recommended(추천) 표시가 있는 기본값 그대로 → Next
    3. Build with Google(플러그인 목록) 화면은 아무것도 체크하지 않고 Next (수업에 필요 없음, 나중에 Settings에서 변경 가능)
    4. Sign in with Google → 크롬에서 1차시와 같은 구글 계정 선택 → 허용 → IDE 창으로 돌아오기
    5. 약관(Terms of Use) 화면은 동의 후 진행. 나머지 질문도 기본값 그대로
    영어 화면이지만 대부분 Next(다음)만 누르면 됨. 모르겠으면 기본값 그대로 두고 강사에게 질문.

    ③ 오늘 폴더 준비 (파워셸 · 오늘 처음 한 번만)

    1차시의 규칙표(AGENTS.md)와 자기소개 페이지(index.html)를 오늘 폴더로 복사합니다. 파워셸을 열고 붙여넣기.

    Windows PowerShell오늘 폴더 준비 · 오늘 처음 한 번만
    cd C:\ai-class; mkdir day2 -Force; copy day1\AGENTS.md, day1\index.html day2

    ④ IDE에서 오늘 폴더 열기

    1. Antigravity IDE 실행 → 위쪽 메뉴 File → Open Folder…
    2. C:\ai-class\day2 폴더를 고르고 폴더 선택 (처음 열 때 'Do you trust the authors…?' 창이 뜨면 Yes, I trust the authors)
    3. 왼쪽 파일 목록 맨 위에 폴더 이름(DAY2)이 보이면 성공. 오른쪽 AI 패널이 안 보이면 Ctrl+L
    AI 패널 사용법 아래 입력칸에 프롬프트를 붙여넣고(Ctrl+V) Enter. 입력칸 근처의 모드를 Fast로 두면 바로 작업함 (Planning은 계획서를 먼저 보여 주고 Proceed를 눌러야 진행). AI가 명령 실행이나 파일 수정 허락을 구하면 내용을 읽고 Accept · Run 같은 버튼으로 허락.
    AI 비서는 연 폴더 안에서만 일함 그래서 차시마다 그날 폴더를 준비해서 엽니다. ③ 줄은 오늘 처음 한 번만. 다시 붙여넣으면 오늘 고친 index.html이 1차시 것으로 덮어써짐.

    이렇게 되면 성공! 왼쪽 파일 목록에 AGENTS.md와 index.html이 보이고, 오른쪽에 AI 패널 입력칸이 보임.

    안 되면?
    빨간 글씨 '… 경로는 존재하지 않으므로 찾을 수 없습니다'지난 차시 폴더나 파일이 없는 경우(결석 등). 1차시 '막혔을 때 쓰는 정답 코드'의 AGENTS.md를 메모장으로 오늘 폴더에 저장한 뒤 다음 단계 진행. 다른 파일은 그 차시의 '막혔을 때 쓰는 정답 코드' 사용.
    'Windows의 PC 보호' 파란 창추가 정보 → 실행. 회사·기관 노트북은 설치가 막혀 있을 수 있으니 강사에게 알리기.
    로그인 뒤 IDE로 돌아오지 않음브라우저에 나온 열기(Open) 버튼 누르기. 없으면 작업 표시줄에서 IDE 창을 직접 클릭.
    회사·기관 구글 계정으로 로그인 불가개인 Gmail 계정으로 로그인.
    AI가 크롬 확장 프로그램 설치나 브라우저 열기를 물음이 수업에는 필요 없음 → 거절. 페이지는 크롬 주소창에 경로를 넣어 직접 열기.

    손 인식 페이지 만들기

    아래 프롬프트에는 AI가 실수하지 않도록 [기술 조건]을 넣어 두었습니다. 어려운 주소는 이해하지 않아도 됩니다. 프롬프트 속 https://cdn… 주소는 손 인식 AI 부품을 빌려 오는 CDN 주소(인터넷 창고 주소)입니다.

    AI 비서에게IDE 오른쪽 AI 패널 입력칸에 붙여넣고 Enter
    hand.html 파일을 만들어 줘. 노트북 카메라로 내 손을 비추면 손가락 마디에 점 21개와 연결선을 그려 주는 페이지야. '카메라 켜기' 버튼을 누르면 시작하고, 화면은 거울처럼 좌우를 뒤집어 줘. [기술 조건] 서버 없이 크롬에서 파일을 바로 열어서 쓸 거야. MediaPipe의 GestureRecognizer를 쓰고, 라이브러리는 https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@1.0.1/vision_bundle.mjs 에서 import 해 줘. wasm 경로는 https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@1.0.1/wasm 이고, 모델은 https://storage.googleapis.com/mediapipe-models/gesture_recognizer/gesture_recognizer/float16/1/gesture_recognizer.task 야. runningMode는 VIDEO, 손은 1개만 인식해 줘.

    이렇게 되면 성공! AI가 hand.html 생성 완료를 알리고, 왼쪽 파일 목록에 hand.html이 생김.

  3. 3

    열고 카메라 허용하기

    크롬 주소창에 아래 주소 붙여넣기. AI가 python -m http.server나 localhost:8000 같은 서버 방법을 알려 줘도 따라 하지 않기 (이 수업은 서버 없이 파일을 바로 엶).

    크롬 주소창주소창에 붙여넣고 Enter
    C:\ai-class\day2\hand.html
    1. 카메라 켜기 버튼 클릭
    2. 주소창 아래 카메라 권한 창에서 허용
    3. 손바닥을 카메라에 비추기 (처음에는 AI 모델을 내려받느라 10초~1분 소요)

    이렇게 되면 성공! 손을 움직이면 점 21개와 선이 손을 따라다님.

    안 되면?
    'localhost에서 연결을 거부했습니다' 화면AI가 알려 준 서버 주소(localhost:8000)로 연 경우. 서버는 필요 없음 → 크롬 주소창에 C:\ai-class\day2\hand.html 붙여넣기.
    '파일에 액세스할 수 없음' 화면C:\ai-class\day2에 hand.html이 없다는 뜻. IDE에서 다른 폴더를 열어 둔 경우가 대부분. AI 패널에 "방금 만든 hand.html 파일의 전체 경로를 알려 줘."라고 물어 그 경로를 주소창에 붙여넣기. 바로잡으려면 File → Open Folder…로 C:\ai-class\day2를 연 뒤 2단계 프롬프트 다시 보내기.
    카메라 화면이 나오지 않음주소창 왼쪽 아이콘 → 카메라 허용으로 변경 → F5. 줌·카메라 앱처럼 카메라를 쓰는 프로그램은 종료.
    화면이 하얗거나 아무 반응 없음F12 → Console 탭의 빨간 글씨를 복사해 AI에게 "hand.html에서 이런 오류가 나. 고쳐 줘: (붙여넣기)"라고 전송.
    계속 안 될 때아래 '막혔을 때 쓰는 정답 코드'의 hand.html을 메모장으로 저장해 사용. 3~5단계 기능이 모두 들어 있음.

    손가락 개수 세기

    AI에게 '펴진 손가락'을 구별하는 규칙 알려 주기. 위 그림의 점 번호와 함께 읽어 보기.

    AI 비서에게IDE 오른쪽 AI 패널 입력칸에 붙여넣고 Enter
    hand.html에 펴진 손가락 개수(0~5)를 세는 기능을 추가해서 화면 오른쪽에 아주 큰 숫자로 보여 줘. 엄지는 손끝(4번 점)이 새끼손가락 뿌리(17번 점)에서 엄지 둘째 마디(3번 점)보다 멀면 펴진 것으로, 나머지 네 손가락은 손끝(8, 12, 16, 20번 점)이 손목(0번 점)에서 둘째 마디(6, 10, 14, 18번 점)보다 멀면 펴진 것으로 판단해 줘. 숫자가 깜빡이지 않게 같은 개수가 0.3초 이상 유지될 때만 바꿔 줘.

    크롬에서 F5를 누르고 다시 카메라 켜기.

    이렇게 되면 성공! 펴는 손가락 개수에 따라 큰 숫자가 0~5로 바뀜.

    웹에 올려 공유하기 (깃허브 Pages)

    지금까지 만든 페이지는 내 노트북에서만 열립니다. 깃허브(GitHub)의 무료 기능 GitHub Pages로 올리면 https://아이디.github.io 같은 인터넷 주소가 생겨 휴대폰으로도 열 수 있습니다.

    ① 자기소개 페이지에 버튼 달기

    오늘 폴더의 index.html(1차시에서 복사해 온 자기소개 페이지)에 손 인식 페이지로 가는 버튼을 답니다. 인터넷 주소의 첫 화면 파일 이름은 반드시 index.html.

    AI 비서에게IDE 오른쪽 AI 패널 입력칸에 붙여넣고 Enter
    index.html 맨 아래에 '🖐 손 인식 체험하기' 버튼을 넣어서 누르면 hand.html로 이동하게 해 줘.

    ② 저장소 만들기 (처음 한 번)

    저장소(repository)는 깃허브에 만드는 내 프로젝트 폴더입니다. 깃허브 화면은 영어이므로 굵은 글씨의 버튼 이름을 찾아 누르기.

    1. 크롬 새 탭에서 아래 주소를 열고 로그인 (미리 가입해 둔 계정)
    2. Repository name 칸에 내아이디.github.io 입력 (예: 아이디가 hong-jeju이면 hong-jeju.github.io)
    3. Public(공개)이 선택된 그대로 아래쪽 초록 버튼 Create repository 클릭
    크롬 주소창주소창에 붙여넣고 Enter
    github.com/new

<script type="module">
  import { FilesetResolver, GestureRecognizer, DrawingUtils }
    from "https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@1.0.1/vision_bundle.mjs";
  window.handAppStarted = true;

  // ── 주소 설정 ─────────────────────────────────────────
  const WASM_URL = "https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@1.0.1/wasm";
  const MODEL_URL = "https://storage.googleapis.com/mediapipe-models/gesture_recognizer/gesture_recognizer/float16/1/gesture_recognizer.task";

  // ── 화면 요소 ─────────────────────────────────────────
  const video = document.getElementById("video");
  const canvas = document.getElementById("canvas");
  const ctx = canvas.getContext("2d");
  const drawer = new DrawingUtils(ctx);
  const startBtn = document.getElementById("startBtn");
  const countEl = document.getElementById("count");
  const gestureEl = document.getElementById("gesture");
  const statusEl = document.getElementById("status");
  const coverEl = document.getElementById("cover");
  const showNumbers = document.getElementById("showNumbers");

  // AI가 알려 주는 손 모양 이름 → 한국어 + 이모지
  const GESTURE_NAMES = {
    Closed_Fist: "✊ 주먹",
    Open_Palm: "🖐 보",
    Pointing_Up: "☝ 하나",
    Victory: "✌ 브이",
    Thumb_Up: "👍 최고",
    Thumb_Down: "👎 별로",
    ILoveYou: "🤟 사랑해",
  };

  let recognizer = null;
  let lastVideoTime = -1;
  let candidate = null;      // 지금 보이는 손가락 개수 (아직 확정 전)
  let candidateSince = 0;    // 그 개수가 처음 보인 시각
  let shownCount = null;     // 화면에 확정해서 보여 주는 개수

  // ── 1) AI 모델 불러오기 ────────────────────────────────
  async function loadModel() {
    const vision = await FilesetResolver.forVisionTasks(WASM_URL);
    const options = (delegate) => ({
      baseOptions: { modelAssetPath: MODEL_URL, delegate: delegate },
      runningMode: "VIDEO",
      numHands: 1,
    });
    try {
      recognizer = await GestureRecognizer.createFromOptions(vision, options("GPU"));
    } catch (e) {
      // 그래픽 가속(GPU)이 안 되는 노트북이면 CPU로 다시 시도
      recognizer = await GestureRecognizer.createFromOptions(vision, options("CPU"));
    }
  }

  loadModel().then(() => {
    startBtn.disabled = false;
    startBtn.textContent = "📷 카메라 켜기";
    statusEl.textContent = "✅ AI 준비 완료. '카메라 켜기' 버튼 클릭";
  }).catch((e) => {
    console.error(e);
    statusEl.textContent = "❌ AI 모델 불러오기 실패. 인터넷 연결 확인 후 새로고침(F5)";
  });

  // ── 2) 카메라 켜기 ─────────────────────────────────────
  startBtn.addEventListener("click", async () => {
    startBtn.disabled = true;
    try {
      const stream = await navigator.mediaDevices.getUserMedia({
        video: { width: 640, height: 480 }, audio: false,
      });
      video.srcObject = stream;
      await video.play();
      canvas.width = video.videoWidth;
      canvas.height = video.videoHeight;
      coverEl.style.display = "none";
      startBtn.textContent = "🎥 카메라 켜짐";
      statusEl.textContent = "🖐 카메라에 손바닥 비추기";
      requestAnimationFrame(loop);
    } catch (e) {
      console.error(e);
      startBtn.disabled = false;
      if (e.name === "NotAllowedError") {
        statusEl.textContent = "❌ 카메라 권한 차단 상태. 주소창 왼쪽 아이콘 → 카메라 '허용' → 새로고침(F5)";
      } else if (e.name === "NotReadableError") {
        statusEl.textContent = "❌ 다른 프로그램(줌, 카메라 앱 등)이 카메라 사용 중. 해당 프로그램 종료 후 다시 클릭";
      } else {
        statusEl.textContent = "❌ 카메라 켜기 실패: " + e.message;
      }
    }
  });

  // ── 3) 손가락 개수 세기 ────────────────────────────────
  // 두 점 사이의 거리
  function dist(a, b) {
    return Math.hypot(a.x - b.x, a.y - b.y, (a.z || 0) - (b.z || 0));
  }

  // 점 21개(p)를 보고 펴진 손가락 개수(0~5)를 셉니다.
  function countFingers(p) {
    let count = 0;
    // 엄지: 손끝(4)이 새끼손가락 뿌리(17)에서 엄지 둘째 마디(3)보다 멀면 '펴짐'
    if (dist(p[4], p[17]) > dist(p[3], p[17])) count++;
    // 검지·중지·약지·새끼: 손끝이 손목(0)에서 둘째 마디보다 멀면 '펴짐'
    const tips = [8, 12, 16, 20];   // 손끝 번호
    const pips = [6, 10, 14, 18];   // 둘째 마디 번호
    for (let i = 0; i < 4; i++) {
      if (dist(p[tips[i]], p[0]) > dist(p[pips[i]], p[0])) count++;
    }
    return count;
  }

  // ── 4) 매 화면마다 반복 ────────────────────────────────
  function loop() {
    if (video.readyState >= 2 && video.currentTime !== lastVideoTime) {
      lastVideoTime = video.currentTime;
      try {
        const result = recognizer.recognizeForVideo(video, performance.now());
        drawFrame(result);
        updateInfo(result);
      } catch (e) {
        console.error(e);
        statusEl.textContent = "⚠️ 손 인식 중 오류 발생. 새로고침(F5) 필요";
      }
    }
    requestAnimationFrame(loop);
  }

  // 카메라 영상 + 손 점 그리기 (거울처럼 좌우 반전)
  function drawFrame(result) {
    const w = canvas.width, h = canvas.height;
    ctx.save();
    ctx.translate(w, 0);
    ctx.scale(-1, 1);
    ctx.drawImage(video, 0, 0, w, h);
    ctx.restore();

    for (const hand of result.landmarks) {
      const mirrored = hand.map((pt) => ({ ...pt, x: 1 - pt.x }));
      drawer.drawConnectors(mirrored, GestureRecognizer.HAND_CONNECTIONS, { color: "#ffffff", lineWidth: 4 });
      drawer.drawLandmarks(mirrored, { color: "#ff7a00", fillColor: "#ffb547", lineWidth: 2, radius: 6 });
      if (showNumbers.checked) {
        ctx.font = "bold 18px sans-serif";
        ctx.fillStyle = "#00e0ff";
        mirrored.forEach((pt, i) => ctx.fillText(String(i), pt.x * w + 8, pt.y * h - 8));
      }
    }
  }

  // 손가락 개수와 손 모양 이름 보여 주기
  function updateInfo(result) {
    let fingers = -1;   // -1 = 손이 안 보임
    if (result.landmarks.length === 0) {
      gestureEl.textContent = "손이 보이지 않음";
    } else {
      const points = (result.worldLandmarks && result.worldLandmarks[0]) || result.landmarks[0];
      fingers = countFingers(points);

      // AI가 손 모양을 확실히(60% 이상) 알아본 경우 이름 보여 주기
      const top = result.gestures[0] && result.gestures[0][0];
      const sure = top && top.score >= 0.6 ? top.categoryName : "";
      gestureEl.textContent = GESTURE_NAMES[sure] || "🤔 (모르는 모양)";
      // 주먹·엄지척은 AI의 손 모양 판단이 더 정확하므로 그 결과 사용
      if (sure === "Closed_Fist") fingers = 0;
      if (sure === "Thumb_Up" || sure === "Thumb_Down") fingers = 1;
    }
    stabilize(fingers);
  }

  // 같은 개수가 0.3초 이상 유지될 때만 화면 숫자 변경 (깜빡임 방지)
  function stabilize(fingers) {
    const now = performance.now();
    if (fingers !== candidate) {
      candidate = fingers;
      candidateSince = now;
      return;
    }
    if (now - candidateSince < 300 || fingers === shownCount) return;
    shownCount = fingers;
    if (fingers < 0) {
      countEl.textContent = "-";
      statusEl.textContent = "🖐 카메라에 손바닥 비추기";
    } else {
      countEl.textContent = String(fingers);
      statusEl.textContent = "👀 손가락 " + fingers + "개 인식";
    }
  }

// 🆘 모스부호 SOS: 짧게 3번(S) → 길게 3번(O) → 짧게 3번(S)
const int LED = 9;              // LED가 연결된 핀 번호

// LED를 onTime(밀리초) 동안 켰다가 끄는 함수
void blinkLed(int onTime) {
  digitalWrite(LED, HIGH);      // 켜기
  delay(onTime);                // onTime 만큼 기다리기
  digitalWrite(LED, LOW);       // 끄기
  delay(200);                   // 깜빡임 사이 쉬는 시간 0.2초
}

void setup() {
  pinMode(LED, OUTPUT);         // 9번 핀을 출력으로 사용
}

void loop() {
  for (int i = 0; i < 3; i++) {
    blinkLed(200);              // S: 짧게 (0.2초) 3번
  }
  for (int i = 0; i < 3; i++) {
    blinkLed(600);              // O: 길게 (0.6초) 3번
  }
  for (int i = 0; i < 3; i++) {
    blinkLed(200);              // S: 짧게 3번
  }
  delay(2000);                  // 2초 쉬었다가 처음부터 다시
}

// 📨 컴퓨터에서 숫자(0~5)를 받아 LED를 켜는 '수신기' 코드
//    시리얼 모니터 직접 입력 또는 5차시 손 인식 웹페이지에서 전송
//    0 = 모두 끄기, 1 = 빨강, 2 = 빨강+노랑, 3·4·5 = 세 개 모두
const int RED = 9;       // 빨강 LED는 9번 핀
const int YELLOW = 10;   // 노랑 LED는 10번 핀
const int GREEN = 11;    // 초록 LED는 11번 핀

// 숫자 n 만큼 LED를 켜는 함수 (최대 3개)
void showLeds(int n) {
  if (n >= 1) {
    digitalWrite(RED, HIGH);     // 1 이상이면 빨강 켜기
  } else {
    digitalWrite(RED, LOW);
  }
  if (n >= 2) {
    digitalWrite(YELLOW, HIGH);  // 2 이상이면 노랑 켜기
  } else {
    digitalWrite(YELLOW, LOW);
  }
  if (n >= 3) {
    digitalWrite(GREEN, HIGH);   // 3 이상이면 초록 켜기
  } else {
    digitalWrite(GREEN, LOW);
  }
}

void setup() {
  Serial.begin(9600);            // 컴퓨터와 대화 시작 (속도 9600)
  pinMode(RED, OUTPUT);
  pinMode(YELLOW, OUTPUT);
  pinMode(GREEN, OUTPUT);
  showLeds(0);                   // 처음에는 모두 끄기
  Serial.println("준비 완료: 0~5 숫자 입력");
}

void loop() {
  if (Serial.available() > 0) {  // 컴퓨터가 보낸 글자가 있으면
    char c = Serial.read();      // 글자 하나 읽기
    if (c >= '0' && c <= '5') {  // 0~5 숫자일 때만 반응 (엔터 같은 다른 글자는 무시)
      int n = c - '0';           // 글자 '3' → 숫자 3 으로 바꾸기
      showLeds(n);
      Serial.print("받은 숫자: ");
      Serial.println(n);         // 받은 숫자를 컴퓨터에 다시 알려 주기
    }
  }
}

  function countFingers(p) {

    // 엄지: 손끝(4)이 새끼손가락 뿌리(17)에서 엄지 둘째 마디(3)보다 멀면 '펴짐'

    // 검지·중지·약지·새끼: 손끝이 손목(0)에서 둘째 마디보다 멀면 '펴짐'
    const tips = [8, 12, 16, 20];
    const pips = [6, 10, 14, 18];
    for (let i = 0; i < 4; i++) {
      if (dist(p[tips[i]], p[0]) > dist(p[pips[i]], p[0])) count++;
    }
    return count;
  }

  function loop() {
    if (video.readyState >= 2 && video.currentTime !== lastVideoTime) {
      lastVideoTime = video.currentTime;
      try {
        const result = recognizer.recognizeForVideo(video, performance.now());
        drawFrame(result);
        updateInfo(result);
      } catch (e) {
        console.error(e);
        statusEl.textContent = "⚠️ 손 인식 중 오류 발생. 새로고침(F5) 필요";
      }
    }
    requestAnimationFrame(loop);
  }

  // 카메라 영상 + 손 점 그리기 (거울처럼 좌우 반전)
  function drawFrame(result) {
    const w = canvas.width, h = canvas.height;
    ctx.save();
    ctx.translate(w, 0);
    ctx.scale(-1, 1);
    ctx.drawImage(video, 0, 0, w, h);
    ctx.restore();
    for (const hand of result.landmarks) {
      const mirrored = hand.map((pt) => ({ ...pt, x: 1 - pt.x }));
      drawer.drawConnectors(mirrored, GestureRecognizer.HAND_CONNECTIONS, { color: "#ffffff", lineWidth: 4 });
      drawer.drawLandmarks(mirrored, { color: "#ff7a00", fillColor: "#ffb547", lineWidth: 2, radius: 6 });
    }
  }

  function updateInfo(result) {
    let fingers = -1;   // -1 = 손이 안 보임
    if (result.landmarks.length === 0) {
      $("gesture").textContent = "손이 보이지 않음";
    } else {
      const points = (result.worldLandmarks && result.worldLandmarks[0]) || result.landmarks[0];
      fingers = countFingers(points);
      const top = result.gestures[0] && result.gestures[0][0];
      const sure = top && top.score >= 0.6 ? top.categoryName : "";
      $("gesture").textContent = GESTURE_NAMES[sure] || "🤔 (모르는 모양)";
      // 주먹·엄지척은 AI의 손 모양 판단이 더 정확하므로 그 결과 사용
      if (sure === "Closed_Fist") fingers = 0;
      if (sure === "Thumb_Up" || sure === "Thumb_Down") fingers = 1;
    }
    stabilize(fingers);
  }

  // 같은 개수가 0.3초 이상 유지되면 '확정', 바뀌었을 때만 아두이노로 전송
  function stabilize(fingers) {
    const now = performance.now();
    if (fingers !== candidate) {
      candidate = fingers;
      candidateSince = now;
      return;
    }
    if (now - candidateSince < 300 || fingers === shownCount) return;
    shownCount = fingers;
    if (fingers < 0) {
      $("count").textContent = "-";      // 손이 없으면 전송하지 않고 대기
      statusEl.textContent = "🖐 카메라에 손바닥 비추기";
      return;
    }
    $("count").textContent = String(fingers);
    statusEl.textContent = writer
      ? "👀 손가락 " + fingers + "개 → 아두이노로 전송"
      : "👀 손가락 " + fingers + "개 인식 (아두이노 연결 시 LED 점등)";
    if (fingers !== lastSent) sendNumber(fingers);
  }

//    시리얼 모니터 직접 입력 또는 5차시 손 인식 웹페이지에서 전송
//    0 = 모두 끄기, 1 = 빨강, 2 = 빨강+노랑, 3·4·5 = 세 개 모두
const int RED = 9;       // 빨강 LED는 9번 핀
const int YELLOW = 10;   // 노랑 LED는 10번 핀
const int GREEN = 11;    // 초록 LED는 11번 핀

// 숫자 n 만큼 LED를 켜는 함수 (최대 3개)
void showLeds(int n) {
  if (n >= 1) {
    digitalWrite(RED, HIGH);     // 1 이상이면 빨강 켜기
  } else {
    digitalWrite(RED, LOW);
  }
  if (n >= 2) {
    digitalWrite(YELLOW, HIGH);  // 2 이상이면 노랑 켜기
  } else {
    digitalWrite(YELLOW, LOW);
  }
  if (n >= 3) {
    digitalWrite(GREEN, HIGH);   // 3 이상이면 초록 켜기
  } else {
    digitalWrite(GREEN, LOW);
  }
}

void setup() {
  Serial.begin(9600);            // 컴퓨터와 대화 시작 (속도 9600)
  pinMode(RED, OUTPUT);
  pinMode(YELLOW, OUTPUT);
  pinMode(GREEN, OUTPUT);
  showLeds(0);                   // 처음에는 모두 끄기
  Serial.println("준비 완료: 0~5 숫자 입력");
}

void loop() {
  if (Serial.available() > 0) {  // 컴퓨터가 보낸 글자가 있으면
    char c = Serial.read();      // 글자 하나 읽기
    if (c >= '0' && c <= '5') {  // 0~5 숫자일 때만 반응 (엔터 같은 다른 글자는 무시)
      int n = c - '0';           // 글자 '3' → 숫자 3 으로 바꾸기
      showLeds(n);
      Serial.print("받은 숫자: ");
      Serial.println(n);         // 받은 숫자를 컴퓨터에 다시 알려 주기
    }
  }

project_party.inoA. LED 파티새 스케치에서 전체 선택(Ctrl+A) 후 붙여넣기
// 🎉 프로젝트 A: 손 신호등 & LED 파티 (부품 추가 없음)
//    손가락 0 = 모두 끄기, 1 = 빨강, 2 = 노랑, 3 = 초록, 4 = 물결, 5 = 파티(모두 깜빡깜빡)
const int RED = 9;       // 빨강 LED는 9번 핀
const int YELLOW = 10;   // 노랑 LED는 10번 핀
const int GREEN = 11;    // 초록 LED는 11번 핀

int mode = 0;                 // 지금 모드 (받은 숫자)
int step = 0;                 // 움직이는 불빛이 몇 번째 단계인지
unsigned long lastTime = 0;   // 마지막으로 불빛을 바꾼 시각 (밀리초)

// 세 LED를 한 번에 켜고 끄는 함수 (HIGH = 켜기, LOW = 끄기)
void setLeds(int r, int y, int g) {
  digitalWrite(RED, r);
  digitalWrite(YELLOW, y);
  digitalWrite(GREEN, g);
}

void setup() {
  Serial.begin(9600);         // 컴퓨터와 대화 시작 (속도 9600)
  pinMode(RED, OUTPUT);
  pinMode(YELLOW, OUTPUT);
  pinMode(GREEN, OUTPUT);
  setLeds(LOW, LOW, LOW);     // 처음에는 모두 끄기
  Serial.println("LED 파티 준비 완료: 0~5 숫자 입력");
}

void loop() {
  // 1) 새 숫자가 들어왔는지 확인하기
  if (Serial.available() > 0) {
    char c = Serial.read();
    if (c >= '0' && c <= '5') {
      mode = c - '0';         // 글자 '4' → 숫자 4
      step = 0;
      Serial.print("모드: ");
      Serial.println(mode);
      if (mode == 0) setLeds(LOW, LOW, LOW);    // 모두 끄기
      if (mode == 1) setLeds(HIGH, LOW, LOW);   // 빨강만
      if (mode == 2) setLeds(LOW, HIGH, LOW);   // 노랑만
      if (mode == 3) setLeds(LOW, LOW, HIGH);   // 초록만
    }
  }

  // 2) 움직이는 불빛 (delay 대신 millis 사용 → 움직이는 중에도 새 숫자를 바로 받음)
  unsigned long now = millis();               // 아두이노가 켜진 뒤 지난 시간

  if (mode == 4 && now - lastTime >= 200) {   // 물결: 0.2초마다 다음 LED로
    lastTime = now;
    if (step == 0) setLeds(HIGH, LOW, LOW);
    if (step == 1) setLeds(LOW, HIGH, LOW);
    if (step == 2) setLeds(LOW, LOW, HIGH);
    step = step + 1;
    if (step > 2) step = 0;                   // 마지막 다음엔 처음으로
  }

  if (mode == 5 && now - lastTime >= 150) {   // 파티: 0.15초마다 모두 깜빡
    lastTime = now;
    if (step == 0) {
      setLeds(HIGH, HIGH, HIGH);
      step = 1;
    } else {
      setLeds(LOW, LOW, LOW);
      step = 0;
    }
  }
}

const int GREEN = 11;    // 초록 LED는 11번 핀

  if (n >= 2) digitalWrite(YELLOW, HIGH); else digitalWrite(YELLOW, LOW);
  if (n >= 3) digitalWrite(GREEN, HIGH);  else digitalWrite(GREEN, LOW);

// 🌈 프로젝트 D: 손으로 바꾸는 무드등 (RGB LED: 빨강 3번, 초록 5번, 파랑 6번 핀)
//    0 = 끄기, 1 = 빨강, 2 = 초록, 3 = 파랑, 4 = 보라, 5 = 무지개
const int R_PIN = 3;       // RGB LED 빨강 다리 (220Ω 저항 거쳐서)
const int G_PIN = 5;       // RGB LED 초록 다리
const int B_PIN = 6;       // RGB LED 파랑 다리
const bool COMMON_ANODE = false;  // 가장 긴 다리를 5V에 꽂는 '공통 양극형'이면 true로 변경

int mode = 0;                 // 지금 모드 (받은 숫자)
int hue = 0;                  // 무지개 색 위치 (0~359)
unsigned long lastTime = 0;   // 마지막으로 색을 바꾼 시각

// 빨강·초록·파랑 밝기(0~255)로 색 만들기
void setColor(int r, int g, int b) {
  if (COMMON_ANODE) {         // 공통 양극형은 밝기를 거꾸로 적용
    r = 255 - r;
    g = 255 - g;
    b = 255 - b;
  }
  analogWrite(R_PIN, r);
  analogWrite(G_PIN, g);
  analogWrite(B_PIN, b);
}

// 무지개 색 계산: 색 위치(0~359) → 빨강 → 초록 → 파랑 → 다시 빨강
void rainbow(int h) {
  int x = h % 120;            // 120 구간 안에서의 위치 (0~119)
  int up = x * 255 / 120;     // 점점 커지는 값 0 → 255
  int down = 255 - up;        // 점점 작아지는 값 255 → 0
  if (h < 120) {
    setColor(down, up, 0);    // 빨강 → 초록
  } else if (h < 240) {
    setColor(0, down, up);    // 초록 → 파랑
  } else {
    setColor(up, 0, down);    // 파랑 → 빨강
  }
}

void setup() {
  Serial.begin(9600);         // 컴퓨터와 대화 시작 (속도 9600)
  pinMode(R_PIN, OUTPUT);
  pinMode(G_PIN, OUTPUT);
  pinMode(B_PIN, OUTPUT);
  setColor(0, 0, 0);          // 처음에는 끄기
  Serial.println("무드등 준비 완료: 0~5 숫자 입력");
}

void loop() {
  if (Serial.available() > 0) {
    char c = Serial.read();
    if (c >= '0' && c <= '5') {
      mode = c - '0';
      if (mode == 0) setColor(0, 0, 0);       // 끄기
      if (mode == 1) setColor(255, 0, 0);     // 빨강
      if (mode == 2) setColor(0, 255, 0);     // 초록
      if (mode == 3) setColor(0, 0, 255);     // 파랑
      if (mode == 4) setColor(160, 0, 255);   // 보라
      Serial.print("색 모드: ");
      Serial.println(mode);
    }
  }

  // 무지개 모드: 0.02초마다 색을 조금씩 바꾸기 (delay 대신 millis 사용)
  if (mode == 5 && millis() - lastTime >= 20) {
    lastTime = millis();
    hue = hue + 1;
    if (hue >= 360) hue = 0;
    rainbow(hue);
  }
}

화면을 AI 비서에게 보여주기

말로 설명하기 어려운 화면은 찍어서 그대로 보여 주기. 찍고, 붙이고, 물어보는 세 단계.

⊞ Win+Shift+S로 찍는 순서

  1. 보여 줄 화면(크롬, 오류 창, 설정 화면 등)을 앞에 띄워 두기
  2. ⊞ Win+Shift+S → 화면이 살짝 어두워지고 위쪽 가운데에 작은 막대 표시
  3. 막대에서 모양 고르기: 사각형(기본, 일부분) · 창(창 하나를 클릭) · 전체 화면
  4. 사각형이면 보여 줄 부분을 마우스로 누른 채 끌었다 놓기 → 자동으로 복사됨

  3. 이어서 궁금한 점을 직접 쓰거나, 아래 상자의 부탁 문장을 복사해 Ctrl+V → Enter

핀 · GND
아두이노의 연결 구멍. 숫자 핀은 신호, GND는 전기가 돌아오는 길(−).
브레드보드
납땜 없이 부품을 꽂는 판. 세로 5칸끼리, +/− 가로줄끼리 연결된 구조.
LED
빛을 내는 부품. 긴 다리가 +(애노드), 짧은 다리가 −(캐소드).
저항 (Ω)
전기가 너무 많이 흐르지 않게 막아 LED를 보호하는 부품. 이 수업은 220Ω.
PWM (~ 핀)
아주 빠르게 켰다 껐다 해서 밝기를 조절하는 기능. ~ 표시 핀(3·5·6·9·10·11)에서 사용 가능.
시리얼 통신
노트북과 아두이노가 USB 선으로 글자를 주고받는 것. 속도(보드레이트)는 9600으로 통일.
Web Serial
크롬이 USB 장치와 시리얼 통신을 하게 해 주는 기능. 연결할 때마다 사용자가 직접 포트를 골라 허락.
포트 (COM)
USB로 연결된 장치의 이름표. 예: COM3. 한 포트는 한 프로그램만 사용 가능.
부저
소리를 내는 부품. 수동 부저는 도레미 연주 가능, 능동 부저는 '삐-' 한 소리만 가능.
서보모터
정해진 각도(0~180도)로 돌아가는 모터. 주황=신호, 빨강=5V, 갈색=GND.
RGB LED
빨강·초록·파랑 세 빛을 섞어 여러 색을 내는 LED.
millis()
아두이노가 켜진 뒤 지난 시간(밀리초). delay 대신 쓰면 기다리는 동안에도 새 명령 수신 가능.
배포 (deploy)
내 컴퓨터의 웹페이지 파일을 인터넷 서버에 올려 누구나 주소로 열 수 있게 하는 일.
깃허브 (GitHub)
파일과 코드를 인터넷에 보관하는 서비스. 무료 기능 GitHub Pages로 웹페이지를 공개할 수 있고, 주소는 아이디.github.io.
저장소 (Repository)
깃허브에 만드는 내 프로젝트 폴더. 사이트용 저장소 이름은 아이디.github.io.
커밋 (Commit changes)
올리거나 고친 파일을 저장소에 확정해 저장하는 일. 깃허브 화면의 초록 버튼.
https
암호화된 인터넷 주소. 카메라·아두이노 연결(Web Serial)은 https 주소나 내 컴퓨터 파일에서만 작동.
데이터베이스
글·숫자 같은 정보를 저장해 두고 여러 사람이 함께 꺼내 쓰는 인터넷 공용 메모장.
Firebase · Firestore
구글의 무료 클라우드 서비스와 그 데이터베이스. 웹페이지에서 바로 글을 저장하고 실시간으로 받아 볼 수 있음. 구글 계정마다 프로젝트를 직접 만들어 씀.
설정값 (firebaseConfig)
내 웹페이지가 내 Firebase 프로젝트를 찾아가는 주소 묶음. 프로젝트에 웹 앱을 등록하면 나옴.
보안 규칙 · 테스트 모드
데이터베이스를 누가 읽고 쓸 수 있는지 정하는 규칙. 테스트 모드는 누구나 읽고 쓸 수 있는 임시 상태(약 30일).
